# Task 1: Iris Flower Classification

## Overview
Machine learning pipeline that classifies iris species (*Setosa*, *Versicolor*, *Virginica*) using sepal and petal measurements.

## Implementation Details
- Built-in Scikit-Learn Iris dataset
- Exploratory Data Analysis with pairplots and boxplots
- 80/20 Stratified train/test split
- Compared Logistic Regression vs Random Forest Classifier
- Metrics: Accuracy, Precision, Recall, F1-Score, and Confusion Matrix
